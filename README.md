# A simple, yet lightweight browser

Montero is a fast, lightweight C# web browser using [CEFSharp](https://github.com/cefsharp/CEFSharp) engine.
Supports dark mode, tabbing and a download system.

## Current features
- Dark mode
- Tabbing system with favicons
- Back, forward, refresh and menu buttons
- Download manager

## System Requirements
- .NET Framework 4.8 on Windows (64-bit)
- [Visual C++ 2019 Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) for the time being
- Windows 8.1, Windows 10 and Windows 11
